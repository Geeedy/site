What a website redesign is

A website redesign is an update of the design, UX, responsiveness and structure of an already existing site while keeping the content and the accumulated SEO rankings. We work with what you already have instead of starting on a blank page. The visuals become more modern, the paths to a lead shorter, the mobile version more convenient, while the texts, pages and their addresses stay the same wherever possible. This is what sets a redesign apart from building a new site, where everything is designed anew from research to markup, and the search weight built up over years is reset along with the old domain or structure.

When a site needs a redesign: the signs

A redesign pays off when the site gets in the way of sales, not just when it looks old-fashioned. Below are the signals that it is time for a rework.

  • Dated visuals. The design looks older than competitors and lowers trust in the first seconds.
  • Poor UX. Long paths to a lead, unclear buttons, heavy forms, the visitor gets lost.
  • Low conversion. Below 2-3% for B2C and below 1% for B2B is a reason to look into the site.
  • No responsiveness. On a phone the layout breaks or is awkward, and mobile traffic leaves.
  • Product or positioning change. The range, audience or offer changed, but the site stayed the same.

According to lpmotor.ru, sites with modern design show 32% higher engagement, so an update pays off beyond the visuals alone.

What we change in a redesign: design, UX, responsiveness, structure

A redesign can be targeted or deep, but we work across four areas.

  • Design. Visual style, design system, typography, colors, a consistent look across all pages.
  • UX. User journeys, navigation, placement and logic of CTAs, simpler forms.
  • Responsiveness. Mobile and tablet versions, speed and comfort on small screens.
  • Structure. Page map, landing pages, block order, so the important things sit closer to the lead.

You can update everything at once, or only the responsive layout or the home page. If the outcome calls for a full corporate website as a separate type rather than a rework of the current one, we will say so honestly at the start.

How we keep SEO rankings during a redesign

This is the key block and our main area of responsibility. Ranking loss after a rework does not come from the new design, but from careless work with addresses and metadata. We close these risks with a safe-release process.

The main rule is simple: do not change URLs without need. If a page ranks well, its address stays the same. When the structure does change, we set a one-to-one 301 redirect from each old URL to a page with the same meaning and intent, not to the home page "just in case." That is how search engines carry the accumulated weight to the new address, according to antonvetrov.ru and seotika.ru.

  • Redirect map. A document in the format "old URL – new URL – 301 type," where every old address has a match. Only 301, because 302 does not pass link weight, and every rule is checked by hand, per seo-smirnov.ru.
  • Baseline metrics before the start. We record keyword rankings, traffic, conversion, the list of top donor pages and all indexable URLs with their meta tags. This is the reference point, per ranx.ru and onepix.ru.
  • Safe release. We build the new site on a test domain closed from indexing. After the move we update sitemap.xml and robots.txt, check indexing and watch behavioral metrics.

The reference point is best fixed in advance and independently, so before a deep redesign we recommend an SEO audit of the current site, to have a snapshot of rankings and entry points before any edits.

If what you need is precisely a move to another host or CMS without a visual rework, your task is a site migration, a separate service. Redesign and migration often go together, and then we combine them in one release with a single redirect map.

Redesign stages

We run the work step by step, with SEO control built into every stage rather than added at the end.

  1. Audit. We examine the current site, measure rankings, traffic and conversion, and find weak UX spots.
  2. URL map. We compile a list of all indexable addresses and decide what stays, what changes, what gets redirected.
  3. Prototype. We design the page structure and user journeys before any drawing, and agree the logic with you.
  4. Design. We draw the mockups in a single design system and show them on desktop and mobile.
  5. Markup. We build responsive pages on a test domain closed from indexing.
  6. Release checklist. We roll out, verify the 301 redirects, update sitemap.xml and robots.txt, and monitor indexing and rankings.

What a redesign does not include

To avoid false expectations, we separate a redesign from adjacent services.

  • Not a migration. Moving to another host or CMS without a design rework is covered by a site migration.
  • Not a site from scratch. Building a new project, rather than reworking the current one, is handled by website development.
  • Not ongoing support. A redesign is a one-off project, while regular small tweaks are separate maintenance.
  • Not graphic design. A logo, brand identity and brand book are work on the brand's style, not on the site.
